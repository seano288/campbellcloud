# Try Time Flies and the new site on the iPad

Status: ready-for-human

Automated checks run in headless Chromium with software WebGL (SwiftShader), which renders the Hangar at a frame or two a
second, so performance, touch and sound need a real iPad.

- [ ] Open the site root from the existing Home Screen icon: the landing page shows both games; Monster Truck Money opens
      with its progress (`mtm2-save`) intact.
- [ ] Time Flies: the voice plays from the first tap; every question is spoken; Help lights the hands while it explains.
- [ ] Set the Clock: dragging either hand with a finger feels right at each Level (hours, quarters, fives).
- [ ] Hangar: orbiting is smooth (aim for 60 fps), hotspots stay on their parts, the Paint and Weapons sheets fit.
- [ ] Take Off: smoke reads as a continuous trail and the afterburner looks good at 60 fps; tricks on tap.
- [ ] Offline: after one online visit to each game, airplane mode and relaunch both from the Home Screen.
- [ ] Add Time Flies to the Home Screen from `/time-flies/` and check its icon.
